# Nelson Njihia

Software engineer and founder of [Synapse Softwares](https://nelsonnjihia-portfolio.vercel.app), based in Nairobi. I build fleet, payments, and business software for companies in East Africa.

### Projects

- **[Protracks](https://jendieprotracks.co.ke)**: Fleet tracking and inventory platform for Jendie Protrack. GPS via iTrack and Protrack APIs, SMS alerts, Supabase.
- **TrackMyKid**: School transport tracking for parents in Nairobi. React Native, Expo.
- **Rahisi-Biz**: Invoicing, inventory, and M-Pesa payments for small businesses.
- **UmojaSDK**: TypeScript and Python SDK for M-Pesa and Airtel Money.
- **[NelsonLabs](https://nelsonlabs.vercel.app)**: Free learning paths for African developers.

### Stack
